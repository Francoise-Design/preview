Françoise Design, Inc. ("Françoise", "we", "us") operates the Françoise Check Figma plugin, Françoise MCP service, and related website (the "Service"). We designed Françoise around data minimization: we collect as little as possible and store almost nothing about your work.

Françoise Design, Inc., a Delaware corporation.

2. What we collect and what we don't

  • Figma user identifier (user_id): the only account identifier we store for plugin users. We do not store your name or email in our database.
  • Design system data: stored in our database solely to power the Service.
  • Layout / mockup / blueprint data: processed in memory only and never stored on our servers. Once processing completes, this data is gone.
  • Billing data: handled entirely by our Merchant of Record, Lemon Squeezy. We do not receive or store card numbers.

We do not run advertising trackers or sell personal information.

3. How the plugin accesses Figma

Françoise Check runs through the Figma Plugin API using the currentuser permission and network requests only. We access only the design content you actively run the plugin on.

4. Service providers & Hosting

  • Microsoft Azure: hosting and database, region North Europe (EU).
  • Lemon Squeezy: Merchant of Record for payments; processes billing and card data on their systems.

Your design systems, mockups, and code contracts are never used to train any AI models.

5. Data retention, GDPR/CCPA rights & DPA

Stored data (design systems, Figma user_id) is deleted within 24 hours of your deletion request to contact@francoise.design. Business customers can request a Data Processing Agreement (DPA) at contact@francoise.design.

Security at Françoise

Françoise is built around a simple idea: the less data we hold, the safer your work is. We collect almost nothing and store even less.

Your mockups and screens are never stored

Layout and blueprint data is processed in volatile memory only and never written to disk. Once processing finishes, it is gone.

LLM-free MCP runtime & No AI training

Inside Françoise MCP, code assembly and icon signature matching run deterministically without external LLM calls at runtime. None of your data is ever used to train any AI models.

EU hosting & VPC isolation

Infrastructure runs on Microsoft Azure in North Europe (EU) with TLS encryption in transit, 2FA need-to-know access controls, 24-hour deletion on request, and 72-hour incident notification. Isolated VPC / on-prem deployment, SOC 2 documentation, and signed DPAs are available via contact@francoise.design.
